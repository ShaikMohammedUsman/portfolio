# Shaik Mohammed Usman — Portfolio

A clean, light, animated portfolio built with plain HTML, CSS and JavaScript.

## Run in VS Code
1. Extract the ZIP.
2. Open the `shaik-portfolio` folder in VS Code.
3. Open `index.html` with Live Server, or double-click `index.html`.

## Files
- `index.html` — portfolio content
- `style.css` — light responsive design and animations
- `script.js` — scroll reveal and mobile menu
- `profile.jpg` — profile photo
- `resume.pdf` — resume
